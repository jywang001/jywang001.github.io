DiscoveryRSI Lab

同一个模型、同一套任务、同一个起始假设池：让 AI 自己迭代 20 轮，和"人类挑选假设"、"人类先批评、AI 再挑"两种人在环路方式对比，看人的介入到底改变了什么。

请先读这条：本页 B、C 两臂中的"人类"决策，实际上全部由 Claude Opus 代为完成（作者授权），不是真人实验。Claude 在决策时能看到同一任务其他臂的进展，存在信息污染，详见披露。这是一项工程试跑（pilot），每个 MLE 任务只有 1 个重复，结论只能当作线索。

实验设计

A · AI 自主

每轮 AI 生成 3 个候选假设，自己选 1 个，写实验代码，跑对照/干预，读结果，进入下一轮。

B · 人类选择

流程同 A，但每轮由"人类"在 3 个候选中挑选要执行的一个（可附理由）。本试跑中由 Claude 代选。

C · 人类批评 → AI 选择

"人类"先对 3 个候选写批评意见，AI 读完批评后自己做选择，并在下一轮生成时参考。本试跑中由 Claude 代写批评。

20轮 / 臂
3候选假设 / 轮
4个任务（1 Nature + 3 MLE-bench）
360轮对照实验

每一轮都是一次对照实验：控制组 = 当前最优方案（incumbent），干预组 = 在其上实施所选假设的改动，两者在同一环境下运行并打分。AI 随后写反思，把证据标为 、、 或 。三臂共享同一个初始候选池，第 1 轮起点相同。

MLE-bench：迭代时只看从公开训练集切出的验证集分数；官方私有测试集只在最后对"验证集最优"方案评一次，并对照 Kaggle 排行榜奖牌线。Nature 任务（两模态单细胞聚类，s43588-024-00689-2）：用原题官方指标 mean_g 在线反馈，没有独立的未见测试集，跑了 3 个重复（replicate）。

披露与局限

决策者与信息污染

  • B、C 两臂的全部选择与批评由 Claude Opus 代为完成，没有真人参与；"人类耗时"只是 Claude 的处理延迟。
  • Claude 在为某一臂做决定时，能看到同一任务其他臂的进展，因此 B/C 之间、以及 B/C 与 A 之间并非独立。已知的具体情形：
    • Spooky：B 臂选用 C=4.0 正则化时，已经知道 C 臂对应的结果；B 臂的温度校准出现在 C 臂建议温度校准之后；C 臂"字符特征权重 0.5"呼应了 B 臂。
    • Spooky C 第 13 轮被标记为"实现与假设不符"，原因是 Claude 的批评与假设原文相冲突。
    • NOMAD：C 臂批评建议的"每原子体积"特征，B 臂此前已用过。
    • Tabular：C 臂推动 num_leaves 调参时已知 B 臂在 num_leaves 上的收益；C 臂降低 feature_fraction 优先级时已知 B 臂 colsample 0.6 失败；对"频次特征"曾写"再失败就放弃"，之后又给了一次机会。
  • Claude 在决策中使用了自身的领域知识（例如各 Kaggle 题的常见做法），这相当于一位有经验的人类，但不代表普通参与者。
  • 每轮决策只依据本次重复内的信息，未使用其他重复（replicate）的结果。

执行与评测

  • NOMAD C 第 16、17 轮的实现读取了验证集标签，已被反思标为"实现与假设不符"；这两轮的分数不可信。
  • Nature 第 2 个重复中，B 臂在同一基线上反复出现"实现与假设不符"。
  • Nature 共有 7 次基础设施故障（非模型原因），这些轮次在隔离失败记录后重跑。
  • MLE-bench 只跑在 8 CPU / 16 GiB / 每次 600 秒的沙箱里，不是官方 24 小时 agent 协议；奖牌线仅作参照，不是官方成绩。
  • Nature 任务没有独立测试集，最终分数就是迭代时看到的最好分数，存在对在线反馈过拟合的可能；官方有效性评审未运行。
  • 每个 MLE 任务只有 1 个重复；Nature 只有 3 个重复，且 C 臂均值主要由第 2 个重复（0.224）拉动。
